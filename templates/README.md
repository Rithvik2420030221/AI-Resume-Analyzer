# AI Resume Analyzer

🚀 A web application that analyzes resumes and compares them with job descriptions.

## Features
- Resume upload (PDF)
- Match score using NLP
- Skills extraction
- Missing skills detection
- Feedback system

## Tech Stack
- Python
- Flask
- Scikit-learn
- PyPDF2
- HTML, Bootstrap

## How to Run
pip3 install flask PyPDF2 scikit-learn
python3 app.py
